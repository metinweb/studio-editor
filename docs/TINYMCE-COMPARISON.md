# TinyMCE demo comparison

Audit: September 27, 2026. The [full-featured premium demo](https://www.tiny.cloud/docs/tinymce/latest/full-featured-premium-demo/) was inspected as a running page and through its published plugin/toolbar configuration. This is a capability comparison, not a claim that Studio implements TinyMCE or its licensed plugins. Studio retains its own editor engine.

**Added** means working functionality introduced by this update. **Available** identifies existing Studio functionality. **Partial** and **Missing** deliberately identify remaining differences.

## Verification

`tests/document-tools.spec.js` exercises Word import including an embedded image and unsafe link, reference-order footnotes, removal/undo/reload, anchor renaming, field filling, actual DOCX footnotes/bookmarks, view-only guides, selection toolbar, custom sizes, indentation, typography and responsive flyouts. Existing editing, list, table, science and package checks remain in the CI suite.

## Dependencies

DOCX import lazy-loads [Mammoth](https://github.com/mwilliamson/mammoth.js), distributed under BSD-2-Clause. Conversion output is sanitized before display/insertion; embedded style maps and external file access are disabled. Imports accept DOCX files up to 10 MB with bounded ZIP metadata. Conversion notes are shown rather than claiming perfect layout fidelity. Third-party notices are included in distributions.
